# UsefulMagic for Multiplatform V2

# 与V1的区别？
最大的区别就是支持给法杖切换魔法，然后不同的魔法对法杖有不同的支持


# 依赖
## 关于kotlin
fabric需要 CooParticlesAPI-Fabric 和 Fabric-Language-Kotlin 作为前置

neoforge需要 CooParticlesAPI-NeoForge 和 KotlinForForge 作为前置

## 关于CooParticlesAPI
更新后会标识推荐的版本， 因为这个API会频繁改动渲染，所以新版未必支持

## 新增依赖
geckolib4 新的生物和法杖动作会用到这个依赖
